The Para-academic Handbook: a free ePub conversion

This repository contains a free ePub conversion of the following work: 

Wardrop, A., & Withers, D. (2014). The Para-Academic Handbook A Toolkit 
for Making-Learning-Creating-Acting. Intellect. 
https://directory.doabooks.org/handle/20.500.12854/34622

In addition to the link in the citation above, a PDF publication of this 
work is available at:
https://library.oapen.org/bitstream/handle/20.500.12657/42468/PHA_Final.pdf;jsessionid=F3B5166748FB73D8C313D06DA578933C?sequence=1

At the request of a colleague, I converted this PDF to an ePub 3 format 
ebook, for easier reading on a wider variety of devices. It is a 
reflowable ePub, and has an embedded font so that characters not in Latin 
script should display correctly unless the user overrides the font choice. 
The original mixture of serif and sans serif fonts was not replicated in 
the conversion, for simplicity's sake, but almost all of the other 
formatting from the PDF version is replicated.
